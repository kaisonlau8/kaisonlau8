## 💪 SKILL DESCRIPTIONS

- Service-ops **data analysis & regional diagnosis**: throughput, output value, gross margin, 1st/2nd maintenance, renewal, NSS — cross-region comparison, trend & structure breakdown, anomaly hunting on **DMS / FineBI / Excel**.
- **Inspection digitalization** & "one-store-one-file" system built on **Feishu bitable**, scored, ranked, and turned into a quarterly-reusable report pipeline.
- **LLM in production**: complaint analysis with **Aliyun Bailian (DashScope) / DeepSeek / Anthropic** — auto summaries, service-risk tags, inspection-linkage judgment, disposition advice; agent orchestration with **Dify** and custom pipelines.
- **Full-stack** delivery: **Python (FastAPI, scrapers, agents)**, **Node (Express)**, **Vue3**, **React + Vite**, **Next.js**, a bit of **Go** and **Ruby**.
- **Automation glue**: **Feishu bots + bitable middleware**, **GitHub Actions**, **cron** nudges, serverless heartbeat monitoring.
- Comfortable owning the whole loop: business problem → data model → API → frontend → "it just runs every day".
